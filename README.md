# SET-HERE-for-Brass-Band
https://setakoma-works.github.io/SET-HERE-for-Brass-Band/
Interactive seating chart creator for Brass Band conductors and managers.

# Status: The Test Piece Edition (Open Beta)
This application is currently in open rehearsal. Please test the tool and provide feedback to help refine it for the final release.

# About
SET-HERE for Brass Band is a browser-based stage layout and plotting tool designed for brass bands. It allows musical directors and stage managers to design, adjust, and export stage plots using an actual-scale coordinate system. No installation or server is required.

# Key Features
Actual-Scale Layout: The stage is calculated at a scale of 1m = 90px. Dimensions can be adjusted in 0.5m increments with an optional 1m grid for precision.

Standard Preset: Includes a default British Brass Band formation that can be loaded with a single click.

Instrument Palette: Features dedicated icons for chairs, music stands, conductor stands, and a wide variety of percussion including Timpani, Drum Sets, and Mallets.

Resizable Mallets: Adjustable width and depth sliders for instruments like Marimba and Vibraphone to match specific equipment.

Intuitive Controls: Supports drag-and-drop movement, multi-selection boxes, and precise rotation.

Undo / Redo: Full history tracking to revert or re-apply changes easily.

Bilingual Support: Interface can be toggled between English and Japanese.

Export Options: Optimized print stylesheet for saving plots as PDF or printing hard copies.

# Local Use
This is a Single-File React App and requires no build process.

Download or clone this repository.

Open the index.html file in any modern web browser.
